# Agate — release distribution

This repository holds the **published releases** of Agate, an application for
P2P synchronization of engineering documentation. It contains no source code:
the Windows binary is attached to each GitHub release as an asset.

## Downloads

- Latest release: <https://github.com/pragmaticdev-ru/agate/releases/latest>
- All releases: <https://github.com/pragmaticdev-ru/agate/releases>
- Machine-readable latest pointer: [`latest.json`](latest.json)

Each release ships a single self-contained `agate.exe` (no runtime DLLs, no
Visual C++ Redistributable required). The release version is `0.1.<N>`, where
`<N>` is the source-repo build number.

## Verifying a download

`sha256sums.txt` in the repository root lists the checksum of the release asset:

```powershell
Get-FileHash -Algorithm SHA256 .\agate.exe
```

Compare the printed hash with the `agate.exe` line in `sha256sums.txt`.

## Repository layout

| Path | Purpose |
|---|---|
| `LICENSE` | BSD-3-Clause license of the project |
| `VERSION` | Version of the most recent release |
| `plugins/` | Converter-plugin API documentation shipped with the app |
| `sha256sums.txt` | SHA-256 of the release asset |
| `latest.json`, `releases.md` | Metadata regenerated by CI on each release |
| `.github/workflows/publish.yml` | Finalizes a draft release and metadata |

The `Agate <version>` releases are produced locally and finalized by GitHub
Actions; the binary is never committed to this repository's history.
