# Плагины конвертации agate — API v1

> **Внимание.** agate загружает и исполняет любую DLL из каталога `plugins/` с
> правами вашего пользователя. Это означает произвольное исполнение кода.
> Устанавливайте только те плагины, которым доверяете.

## Что делает плагин

Плагин — это динамическая библиотека (`.dll`, Windows x64), которая:

1. объявляет входные расширения файлов, которые agate должен синхронизировать;
2. по запросу конвертирует такой файл в системный формат (PDF или растровое
   изображение), который agate умеет показывать на холсте.

Оригинальный файл никогда не изменяется и продолжает синхронизироваться как
обычная версия документа.

## Каталог и обнаружение

- Положите DLL в каталог `plugins/` рядом с `agate.exe` (или в каталог,
  указанный в `config.toml`, секция `[plugins] dir`).
- Плагины обнаруживаются **только при запуске приложения**. Добавление или
  удаление DLL действует после перезапуска.
- Расширения из загруженных плагинов добавляются к системным. Файлы с этими
  расширениями, найденные в подключённых областях, автоматически импортируются.

## ABI v1

Единственный экспортируемый символ:

```c
__declspec(dllexport) const AgatePluginV1* agate_plugin_v1(void);
```

Полное описание структур — в заголовке `agate_plugin.h`. Правила:

- `abi_version` = 1;
- `id` уникален среди плагинов, `[a-z0-9._-]{1,64}`;
- `extension` — строчные буквы и цифры, без точки, `[a-z0-9]{1,16}`;
- `output` — один из: `pdf`, `png`, `jpg`, `jpeg`, `webp`, `bmp`, `tif`, `tiff`;
- расширение не должно перекрывать системное и не может быть заявлено двумя
  плагинами (побеждает первый по имени файла DLL; конфликт пишется в лог);
- если дескриптор не проходит валидацию, DLL отключается целиком.

## Контракт `convert`

```c
int32_t convert(const char* src, const char* dst, char* err, size_t err_cap);
```

- возвращает `0` при успехе, иначе — ненулевой код;
- при ошибке запишите причину в `err` как NUL-terminated UTF-8 строку;
- **не пропускайте C++-исключения и паники через границу** — это
  неопределённое поведение; функция должна ловить всё внутри себя;
- функция может вызываться из потока, отличного от загрузившего DLL;
- `dst` — путь в каталоге временных файлов; создайте именно этот файл.

## Пример (C++)

```cpp
#include "agate_plugin.h"
#include <string>

static const AgatePluginFormat kFormats[] = {
    { "dwg", "pdf" },
};

static int32_t convert(const char* src, const char* dst, char* err, size_t cap) {
    try {
        // ... convert src to a PDF at dst ...
        return 0;
    } catch (const std::exception& e) {
        if (cap) { std::snprintf(err, cap, "%s", e.what()); }
        return 1;
    } catch (...) {
        if (cap) { std::snprintf(err, cap, "unknown error"); }
        return 1;
    }
}

static const AgatePluginV1 kDescriptor = {
    AGATE_PLUGIN_ABI_VERSION,
    "example.dwg",
    "Example DWG converter",
    "1.0.0",
    1,
    kFormats,
    &convert,
    nullptr,
};

extern "C" __declspec(dllexport) const AgatePluginV1* agate_plugin_v1(void) {
    return &kDescriptor;
}
```

## Масштаб чертежа в PDF

Чтобы холст измерял «Длина»/«Площадь» в единицах чертежа (мм/м) со шкалой
`1:S`, конвертер должен вшить в выходной PDF стандартную таблицу
viewport/`Measure` (ISO 32000 §12.9). Если таблицы нет, agate показывает
значения в сантиметрах листа.

Для каждой страницы задайте viewport с `Measure`:

```
<</Type /Viewport /BBox [x0 y0 x1 y1]
   /Measure <</Type /Measure /Subtype /RL
      /D [<</C 35.28 /F /D /U (mm)>>]     % расстояния
      /A [<</C 1244.7 /F /D /U (mm2)>>]   % площади
      /X [<</C 35.28 /F /D /U (mm)>>]     % координатные (для совместимости)
      /R (1:100)>> >>
```

- `/D`, `/A` (и опциональный `/X`) — number-format: либо один словарь, либо
  массив словарей; agate читает обе формы и берёт первую запись с непустым `/U`;
- `/C` — коэффициент: сколько единиц чертежа приходится на один пункт PDF
  (`1 pt = 1/72 in`); `/F /D` — десятичный формат; `/U` — префикс единицы
  **ASCII-строкой** (`mm`, `mm2`, без «²»); **пустой `/U ( )` означает «масштаба
  нет»** — agate в этом случае честно падает в сантиметры листа;
- `/R` — текстовая подпись шкалы (например, `(1:100)`).

Формула коэффициента: `C = (25.4/72)·S·k`, где `S` — знаменатель шкалы
(`1:S`), а `k` — единицы чертежа на миллиметр:

| Единица | `k` |
|---|---|
| мм | 1 |
| см | 0.1 |
| м | 0.001 |
| дюйм | 1/25.4 |
| фут | 1/304.8 |

Площадь: `A = C²` (единица `/U` — `mm2` и т. п.).

Примеры: чертёж в мм со шкалой 1:100 → `C = (25.4/72)·100·1 ≈ 35.28`;
чертёж в метрах со шкалой 1:500 → `C = (25.4/72)·500·0.001 ≈ 0.176`.

Таблицу можно вшить инкрементальным обновлением PDF (новые объекты + xref +
trailer с `/Prev`), если файл не шифрован, не linearised, без object streams и
с классическим xref; иначе перепишите файл полностью (`lopdf`/аналог). agate
читает обе формы number-format и трактует пустой `/U` как «масштаба нет».

## Кэш и производительность

- Результат конвертации кэшируется в `%LOCALAPPDATA%\agate\plugin-cache`
  и переиспользуется при повторном открытии той же версии файла.
- Лимит кэша задаётся в «Параметрах» (по умолчанию 1 ГиБ, `0` — без ограничения).
- Первое открытие файла занимает время конвертации; повторное — мгновенно.

## Ошибки

Если конвертация не удалась, плагин вернул ошибку, упал или превысил таймаут,
холст показывает экран «Не удалось открыть файл» с причиной. Файл при этом не
удаляется и продолжает синхронизироваться; ошибка плагина не является ошибкой
синхронизации.
